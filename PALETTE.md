# ShelfShare palette

Cozy coffee-house browns with a warm amber accent. Headings use **Fraunces** (serif, 500/700); body text uses **DM Sans** (400/500/700). Both are on Google Fonts.

## Light theme
| Role | Hex | Used for |
|---|---|---|
| Background | `#F2E9DC` | page, behind cards (cream) |
| Card | `#FFFAF2` | cards, inputs |
| Ink | `#2B1D14` | main text (espresso) |
| Muted | `#7B665A` | secondary text |
| Line | `#E3D3C0` | borders, dividers |
| Accent | `#D9923F` | primary buttons, highlights (amber) |
| Accent ink | `#2A1500` | text on amber |
| Brown | `#6B4226` | secondary brand, tags, icons |
| Brown tint | `#EBDAC4` | tag and chip backgrounds |
| Shell | `#D6C5B0` | area around the phone frame |
| Highlight | `#FFFFFF` | request cards |

## Extras

- Owl gray: `#9AA1AA` (body), `#DADDE1` (face), `#8A9099` (wings); beak `#CC8B3A`; eyes `#E6B54F`
- Book cover swatches: `#8C4A3C` `#5B4B3A` `#7A8541` `#6A4A5A` `#B07A2A` `#4E6B3E` `#7A4B2A` `#8A5A44`
